# @bce-tool/linux-x64

Platform-specific binary for [bce-tool](https://github.com/linqiu919/bce-tool-rs) (Linux x64).

## Overview

This package contains the pre-built binary for Linux x64. It is automatically installed as an optional dependency when you run `npx bce-tool` on Linux x64 systems.

**Do not install this package directly.** Instead, use:

```bash
npx bce-tool --base-url <API_URL> --token <AUTH_TOKEN>
```

## Supported Platforms

- Linux x64/amd64
